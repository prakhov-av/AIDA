# Инженерные принципы

## Human in the Loop

Ни одно критически важное действие не выполняется без подтверждения разработчика.

---

## Architecture First

Любая реализация начинается только после утверждения архитектуры.

---

## Documentation First

Документация является частью продукта и создается одновременно с кодом.

---

## Explainable Decisions

Каждое архитектурное решение должно иметь объяснение.

---

## AI Agnostic

AIDA не зависит от конкретной AI-модели.

---

## Project Agnostic

AIDA должна работать с любыми проектами.

---

## Test Before Merge

Любые изменения проходят автоматическую проверку перед ревью.

---

## Dogfooding

После появления первой рабочей версии AIDA должна использоваться для собственной разработки.

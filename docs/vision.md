# Видение проекта

## Долгосрочная цель

Создать платформу, которая позволит одному разработчику эффективно управлять полноценной AI-командой.

Вместо взаимодействия с одним AI пользователь работает с агентством разработки.

Каждый агент отвечает только за свою область ответственности.

---

## Через несколько лет AIDA должна уметь

- анализировать требования;
- строить архитектуру;
- планировать работу;
- распределять задачи между агентами;
- писать код;
- запускать тесты;
- выполнять код-ревью;
- обновлять документацию;
- создавать Pull Request.

Человек утверждает результаты работы и принимает архитектурные решения.

---

## Главная идея

AIDA не заменяет разработчика.

AIDA усиливает разработчика.
